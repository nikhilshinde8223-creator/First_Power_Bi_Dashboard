# First_Power_Bi_Dashboard
# 📊 Power BI Sales Dashboard

## 📌 Project Overview

This project is a Power BI dashboard created to practice and demonstrate skills in **Data Cleaning, Data Transformation, Data Modeling, DAX, and Data Visualization**.

The dashboard provides an interactive view of sales performance and helps identify important business insights.

## 🛠️ Tools & Technologies

* Power BI
* Power Query
* DAX
* Microsoft Excel
* Data Visualization

## 🔄 Data Preparation & Power Query

During this project, I practiced:

* Loading data from Excel files
* Loading data from websites
* Data cleaning
* Handling null/missing values
* Removing duplicate records
* Splitting columns
* Merging queries
* Group By
* Changing data types
* Renaming columns
* Creating calculated columns

## 📊 Dashboard Features

The dashboard includes:

* Total Sales
* Total Profit
* Total Orders
* Average Sales
* Sales by Category
* Sales by Region
* Monthly Sales Trend
* Top Products
* Customer/Category Analysis
* Interactive filters and slicers

## 🧮 DAX Practice

I also practiced DAX concepts such as:

* SUM
* COUNT
* DISTINCTCOUNT
* CALCULATE
* SUMX
* DIVIDE
* IF
* Measures
* Calculated columns

## 🎯 Key Learning

Through this project, I improved my understanding of how to:

1. Import data into Power BI
2. Clean and transform raw data
3. Build relationships between tables
4. Create DAX measures
5. Design interactive dashboards
6. Extract business insights from data
7. Present data in a professional and understandable format
